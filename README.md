# Curry On

A static, mobile-friendly Indian food and movement guide. Familiar household meals, portion guidance, separate meal tables, a gradual twelve-week activity plan, food-label calculations and adjustable daily/weekly planning targets.

## Open

Serve this directory with any static HTTP server, or publish its root on GitHub Pages. No build step, account or backend is required.

## Files

- `index.html`: guide and evidence links
- `data.js`: meal options and illustrative product-label values
- `app.js`: targets, activity schedule, label calculator and browser-only habit ticks
- `styles.css`: responsive and print styles
- `assets/`: original vector illustrations and downloadable visual guides

## Nutrition scope

The energy and macro allocations are adjustable planning examples, not measured maintenance needs. Meal macros are broad estimates, not validated recipe analyses. Product examples must be checked against the current pack. The site does not promise a specific lipid response or avoidance of medication. Clinical references are available within the guide.

## Privacy

No uploaded reports, food diaries, body measurements, medical histories, account identifiers, private photos or workout exports are included. No analytics or third-party scripts are used. Habit ticks and preferences are stored only in the visitor's browser, with a clear-data control. GitHub may retain standard hosting logs; the repository and hosting URL are public.
